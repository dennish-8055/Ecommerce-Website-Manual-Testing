## 📌 Project Overview

This project focuses on manual testing of an e-commerce web application using **SauceDemo**.

The objective is to gain practical experience in software testing activities, including test scenario preparation, test case design, functional testing, test execution, form validation, and defect documentation.

The application is tested from an end-user perspective to verify whether its major functionalities behave as expected.

🌐 **Application Under Test:** [SauceDemo](https://www.saucedemo.com/)

---

## 🎯 Project Objectives

* Understand the Software Testing Life Cycle (STLC).
* Prepare test scenarios and detailed test cases.
* Perform functional testing of an e-commerce application.
* Validate login functionality.
* Test product display and sorting functionality.
* Verify shopping cart operations.
* Test checkout functionality and form validations.
* Validate order summary and price calculations.
* Verify successful order placement.
* Document actual results and test execution status.
* Maintain structured QA documentation.

The following application modules are included in the testing scope:

| Module               | Testing Activities                                     |
| -------------------- | ------------------------------------------------------ |

## 🐞 Bug Reporting

A separate Excel workbook, `Bug-Reports.xlsx`, is maintained for documenting defects identified during testing.

The bug-reporting structure includes:

* Bug ID
* Test Case ID
* Bug Title
* Module
* Environment
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Status

Only reproducible defects should be documented as confirmed bugs. Unverified issues are not presented as confirmed defects.
